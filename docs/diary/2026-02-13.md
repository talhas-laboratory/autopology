# 2026-02-13

## Decisions

- Chose an embedded Python stack for v1 (SQLite + FTS5) to optimize for OSS installability and security.
- Languages targeted for deep indexing in v1: TypeScript/JavaScript and Python.
- Semantic layer is hybrid but opt-in: default is local-only, remote calls require explicit enable + env vars.

## Notes

- The "graph is source of truth" workflow is intentionally deferred. v1 treats the graph as a derived index of the filesystem.
- Visualization will ship as Mermaid export plus a self-contained HTML viewer (no CDN).
- Switched TS/JS parsing to per-language Tree-sitter grammar packages due to API compatibility issues with the bundled `tree-sitter-languages` helper.
