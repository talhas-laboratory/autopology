# Update Policy

AuTopology uses SemVer and immutable artifacts.

## npm

Pinned install:

```bash
npm install -g autopology@1.0.1
```

## Docker

Pinned image:

```bash
docker pull ghcr.io/talhas-laboratory/autology:1.0.1
```

## Homebrew

```bash
brew update
brew upgrade autopology
```

## Notes

- Prefer pinned versions in CI and production.
- Runtime does not perform automatic update checks.
